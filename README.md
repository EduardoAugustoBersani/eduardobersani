## 🧠 Featured Projects

### 📟 ESP32 IoT / Telemetria
> 📡 Firmware em **C/C++** para ESP32 com leitura de sensores e envio de telemetria
> 🔌 Comunicação via **UART / Modbus** e rede (**TCP/IP / MQTT**)
> ⚙️ Base para monitoramento de equipamentos industriais em tempo real
> ✅ **Foco:** confiabilidade em ambiente de chão de fábrica

### 🏭 GATA — Gestão de Atividades do Time de Automação
> 🗂️ Plataforma full-stack que substituiu a planilha compartilhada de registro de atividades
> ⚙️ **Next.js 15 · React 19 · TypeScript · PostgreSQL (Supabase) · Vercel**
> 🧱 Regras de negócio no banco (generated columns, CHECK, RLS) e gráficos SVG server-side
> 📶 SSR para ambientes com sinal ruim + trilha de auditoria por técnico
> ✅ **Resultado:** ~4.400 registros históricos migrados, operação sem planilha

### 💉 Infusion Pump Calculator
> 🧮 Web app para cálculo de doses de medicação em infusão contínua
> ⚙️ **React · TypeScript · Tailwind v4 · Vite · Supabase**
> 🗃️ Arquitetura cache-first, exclusão lógica, catálogo editável sem login
> ✅ **Resultado:** ferramenta prática e rápida para uso clínico

### 📘 Apostila C++ do Zero ao Profissional
> 📚 Livro técnico de **C++** cobrindo do básico ao avançado (28 módulos + suplementos)
> 🛠️ Pipeline de build **pandoc → xelatex**, PDF profissional
> 🧩 Inclui Cheat Sheet, Glossário, prep de entrevista e 30+ desafios
> ✅ **Objetivo:** material de estudo completo para iniciantes → profissionais
